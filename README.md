# StreamVision TV 📺

Live streaming and video broadcasting platform.

## ✨ Features

- 📡 Live streaming
- 🎬 Video on demand
- 👀 Viewer analytics
- 💬 Live chat
- 📺 Multi-channel support

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/antono4/streamvision-tv.git

# Open in browser
cd streamvision-tv
open index.html
```

## 📁 Project Structure

```
streamvision-tv/
├── index.html      # Main page
├── css/            # Stylesheets
├── js/             # JavaScript files
└── assets/         # Static assets
```
